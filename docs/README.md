## 🛠️ Wartung

### Dokumentation aktuell halten

**Regel**: Bei jedem größeren Feature oder Bug-Fix die Dokumentation aktualisieren!

**Was aktualisieren?**
- ✅ `CURRENT_STATE.md` - Bei neuen Features, gelösten Problemen
- ✅ `ARCHITECTURE.md` - Bei Architektur-Änderungen
- ✅ `TESTING.md` - Bei neuen Testing-Patterns
- ✅ `README.md` - Bei Setup-Änderungen

**Wann archivieren?**
- 📦 Wenn Dokumente nicht mehr aktuell sind
- 📦 Verschiebe nach `archive/` mit Jahreszahl im Namen
- 📦 Erstelle README im Archiv mit Kontext
